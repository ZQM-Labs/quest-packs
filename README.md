# Quest Packs — ZQM Labs


Versioned quest packs for **ZQM Labs — Z's Quests & Mischief** location games.
*Games, gear & a little mischief.*


## What lives here


| Path | What it is |
|---|---|
| `sample-quest/` | **Free sample edition** — a complete 6-stop mini quest anyone can play. Try the format before you buy. |
| `editions/` | The edition catalog — one folder per edition with its metadata, contents list, and version history. |


## How editions ship


Each edition is published as a **GitHub Release** from this repo. The release notes describe what's inside; the sample quest's full pack JSON ships publicly. Full paid-edition kits (answer keys, print-ready sign sets) are delivered privately to organizers — this repo carries the catalog and the free sample, never the paid answer keys.

## Pack format


Quest packs are JSON validated by the player (`validatePack`). The format spec, authoring guide, and a validator live in [ZQM-Labs/quest-authoring](https://github.com/ZQM-Labs/quest-authoring).
